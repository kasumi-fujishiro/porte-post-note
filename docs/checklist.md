## 実機で残っている確かめ(iPhoneとAndroid)

1. 営業中:写真 → ひとこと → 共有 までの秒数(3回ほど計り、管理ページの「作業時間」で見る)
2. 次の日に開くと、作りかけと写真が消えている
3. ホーム画面に追加したアプリから、全部の種類の画像を保存・共有できる
4. ホーム画面から開いたアプリで、「登録・確認のページを開く」→ ログイン → 保存 →「アプリに戻る」ができる
5. Androidで、管理ページのカレンダーの「この内容でOK」ができる
6. 暗い表示(ダークモード)でも、画面が読める
