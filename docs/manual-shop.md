# 投稿ノート 説明書(お店の人向け)

Instagramの投稿の画像を、えらぶだけで作るアプリです。言葉とデザインを、その場で考えなくて済むようにしてあります。

- アプリ:https://kasumi-fujishiro.github.io/porte-post-note/
- ログインはいりません(お店の人用のページだけ、Googleのログインがいります)

---

## 1. 開き方

1. お店の裏に貼ってあるQRコードを、スマホのカメラで読みとる
2. 開いたら、**ホーム画面に追加**しておくと、次からはアプリのように開けます
   - iPhone(Safari):下の「共有」ボタン(四角から上に矢印)→「ホーム画面に追加」
   - Android(Chrome):右上の「︙」→「ホーム画面に追加」

**LINEの中で開いたとき**:画面の上に黄色い案内が出ます。保存や共有がうまく動かないことがあるので、右上(または右下)の「…」から「ブラウザで開く」をえらび、SafariかChromeで開いてください。

---

## 2. 営業中(毎日の投稿)

1. 「営業中」をえらぶ
2. 「写真をえらぶ」(または「その場で撮る」)でショーケースの写真を入れる
3. 日付(今日。`10.17` の形)と「OPEN」は、自動で入ります
4. ひとことを入れるときは、状況(雨の日など)→ ひとこと の順にタップします。入れなくてもかまいません
5. 写真の大事なところが文字で隠れるときは、「日付とOPENの位置」を「下」にします。写真の上下の位置も、つまみで動かせます
6. 「**共有する(Instagramへ)**」を押して、Instagramをえらぶ。または「画像を保存する」

**動画を上げるとき**:動画には文字を入れられないので、「えらんだ ひとことをコピー」を押して、Instagramで貼り付けてください。

**途中でお客さんが来たら**:そのまま閉じてかまいません。次に開くと、写真もえらんだ内容も、そのまま残っています(その日のうちだけ。次の日はまっさらから始まります)。

**次の投稿を作るとき**:「新しい投稿を作る」を押すと、写真とひとことが消えます。

### 写真の撮り方の決まり

- **縦長で撮る**
- **商品のまわりに余白を残す**(上下に日付やひとことが入るので、商品がはしに寄りすぎないように)

### 出す前に見るところ

- **日付が今日か**
- **文字が合っているか**(ひとことや商品名に、まちがいがないか)

### iPhoneで保存するとき

「画像を保存する」を押すと、画像は「写真」ではなく「ファイル」アプリの「ダウンロード」に入ります。「写真」に入れたいときは、「共有する」から「画像を保存」をえらんでください。どちらもうまくいかないときは、「うまく保存できないとき」を押して、出てきた画像を長押しして保存します。

---

## 3. 新作・季節

1. 「新作・季節」をえらぶ
2. 商品をえらぶ(商品は、お店の人用のページで登録したものだけが出ます)
3. 写真を入れる
4. ラベル(NEW、季節限定、本日のおすすめ、なし)をえらぶ
5. 共有する、または保存する

---

## 4. 駐車場

「駐車場」をえらぶと、お店で決めた駐車場の案内の画像が入ります。大きさ(ストーリーズ、フィード投稿、店頭掲示 A4)をえらんで、共有するか保存してください。

---

## 5. 営業カレンダー

- お店の人が確認した月のカレンダーだけを、画像にして保存できます
- 日にちを直すのは、お店の人用のページで行います
- 毎月の20日ごろから、アプリのいちばん上に「◯月の営業日を確認してください」と出ます。お店の人に知らせてください(お店の人は「営業日を確認する」から、確認のページを開けます)

---

## 6. お店の人用のページ(登録・確認)

アプリの上の「**登録・確認(お店の人用)**」→「登録・確認のページを開く」で開きます。終わったら、上の「← アプリに戻る」で戻ります。

### 初めて開くとき

- Googleのログインを求められたら、**お店のシートを共有してもらったGoogleアカウント**でログインします
- 「このアプリはGoogleで確認されていません」と出たら、左下の「詳細」→「投稿ノート 管理(安全ではないページ)に移動」→「許可」の順に押します。お店のために作ったものなので、問題ありません。この画面は最初の1回だけです
- ページの上に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」と出ます。毎回出ますが、気にしなくて大丈夫です

### ひとこと

- 「ひとことを足す」で、状況(今あるものをえらぶか、新しく書く)と、ひとことを入れて「登録する」
- 直すときは、その行の「直す」
- 使わなくなったものは「しまう」(2回押します)。消えずに「しまったもの」に入るので、いつでも「戻す」で戻せます
- **価格(500円、¥500 など)は登録できません**(お店の方針で、価格は載せません)
- 「例」の印がついたものは、最初に入れた見本です。直すと印が消えます

### 商品

- 商品名、ひとこと説明(味や特徴)、色をえらんで「登録する」
- 今は出していない商品は、消さずに「しまう」にしておくと、次の季節にまた使えます

### AIに頼む文をコピーする

ひとことや商品の説明を考えるのが大変なときに使います。

1. 「こういう状況」(または商品名と短いメモ)を書く
2. 「この文をコピー」を押す
3. 無料のAI(GeminiやChatGPTなど)に貼り付ける
4. 出てきた案を**読んでから**、使いたいものだけを、登録の欄に貼って登録する(メモにないことが足されていないか、確かめてください)

### お店の設定

営業時間、営業中の色、定休日、カレンダーの日程、カレンダーの投稿先(フィード/ストーリーズ)を変えられます。変えたら「設定を保存する」を押します。

### 営業カレンダーの確認(毎月1回)

| 日 | 起きること |
|---|---|
| 20日 | アプリにお知らせが出て、LINEでも知らせが届く |
| 23日 | まだ確認していなければ、もう一度LINEで知らせが届く |
| 25日の12時台 | 確認ずみなら、Instagramに自動で投稿される |
| 25日より後 | 確認していなければ、投稿されない。あとで確認すると、1時間以内に投稿される |

確認のしかた:

1. 「カレンダー」のタブを開き、何月の分かをえらぶ(LINEやアプリのお知らせから開くと、その月が開きます)
2. 定休日には、はじめから丸がついています。**変わる日だけ**タップします(1回で「お休み」、2回で「時間変更」、3回で「営業」)
3. 必要なら、ひとこと(例:23日は営業します)を入れる
4. お休みの日数と、下の画像を見て、まちがいがなければ「**この内容でOK**」
5. 「確認ずみにしました。◯月25日の12時台に投稿する予約を作りました。画像も公開しました。」と出れば終わりです

- 確認のあとに日にちを直して保存すると、**確認と予約が取り消されます**。もう一度「この内容でOK」を押してください
- 途中でやめるときは「途中まで保存する」

### 最近の投稿(自動の投稿がうまくいかなかったとき)

カレンダーのタブのいちばん下にあります。

- **要確認**:投稿できたか分かりません。Instagramを見て、出ていれば「投稿済みにする」、出ていなければ「もう一度出す」
- **失敗**:自動で投稿できませんでした。「もう一度出す」を押すか、下の「手で投稿するとき」で投稿してください

### 手で投稿するとき(自動の投稿が止まったとき)

カレンダーのタブの「手で投稿するとき」で「画像を保存する」を押し、Instagramのアプリで予約投稿してください。どんなときでも、この方法で出せます。

### 作業時間の記録

「作業時間」のタブで、全員の記録(アプリで投稿を作りはじめてから、保存か共有をするまでの秒数)と平均を見られます。「表計算ソフトに貼れる形でコピー」で、表計算ソフトに貼り付けられます。名前や端末の情報は入っていません。

### 登録できる人

登録できる人は、**お店のシートの共有**だけで決まります。

- 足す:「そのほか」のタブの「シートを開く」→ 右上の「共有」→ その人のGoogleアカウントを入れ、「**編集者**」をえらんで送る
- 外す:同じ画面で、その人の「編集者」→「アクセス権を削除」

## 7. 困ったとき

| こまったこと | すること |
|---|---|
| アプリが開かない | 電波のある所で開き直す。一度開いたことがあれば、電波がなくても開けます |
| 古い画面のまま | 読み込み直す(Safariならアドレスの横の「↻」)。直してから数分は、古いものが出ることがあります。数分おいて、もう一度 |
| 保存できない | 「うまく保存できないとき」を押して、出た画像を長押しで保存 |
| LINEの中で開いてしまった | 「…」→「ブラウザで開く」 |
| お店の人用のページで「このアカウントでは、お店のシートを開けません」 | そのGoogleアカウントに、シートが共有されていません。持ち主に「編集者」として共有してもらう。ちがうアカウントで開いていたら、切りかえる |
| お店の人用のページで「読みこめませんでした」 | Googleのアカウントに2つ以上ログインしていると起きることがあります。使うアカウント1つだけでログインし直すか、プライベートブラウズ(シークレットウィンドウ)で開く |
| 「ほかの人が先に変えました」 | ほかの人が同じときに直しました。新しい内容が読み直されているので、確かめてから、もう一度押す |
| アプリやページの上に、黄色い知らせが出た | 書いてあるとおりにする。「投稿できたか分かりません」は「最近の投稿」で決める。「鍵(トークン)が使えなくなりました」「2日以上動いていません」は、管理する人に知らせる。その月の分は、手で投稿する |

---

## 8. 分かっている限界

- 自動の投稿は12時ちょうどではなく、**12時台**に出ます
- 確認のお知らせは、アプリを開いたときと、LINEでだけ届きます(スマホの通知としては出ません)
- お店の人用のページの上には、Googleの注意書きが出ます。初めて開くときだけ、許可の画面が出ます
- ひとこと、商品、設定、確認ずみのカレンダーは、アプリのURLを知っていれば誰でも見られます。**お客さんに見せてよい内容だけ**を登録してください
- 作りかけの内容と写真は、スマホごとに保存されます(ほかの人のスマホには出ません)
- 写真は、スマホの外に送りません
- Instagramに投稿するための鍵は、およそ90日ごとに作り直しが必要になるかもしれません。その前にLINEで知らせが届くので、管理する人に頼んでください
- アプリのURLは、シェフの名義に移すときに1回変わります。そのときは、新しいQRコードからホーム画面に追加し直してください
